# 語音查詢測試步驟

對麥克風說出測試項目的名稱或編號 → 查 Excel 對照表 → 從喇叭/耳機朗讀完整步驟。

- 線上辨識(Google)+ 線上朗讀(微軟 edge-tts,中文用台灣語音、英文用美式英語)
- **需要網路。** 沒有網路時,程式會用 Windows 內建語音說「網路沒有連線,請檢查網路。連線後會自動繼續。」,之後每 3 秒檢查一次,網路恢復就自動繼續
- 中文用中文念,英文單字/縮寫/型號用英文念;小數與 IP(8.8.8.8)用中文念成「8點8點8點8」

## 執行

```bash
.venv\Scripts\python.exe main.py --in-device 2
```

會開一個**永遠置頂**的大字視窗(預設在螢幕右上角,可拖曳),顯示目前狀態(聆聽中 / 辨識中 / 朗讀中 / 沒有網路)、聽到的文字、項目編號與名稱,以及完整步驟;念到哪一步,那一步就標亮。關閉視窗即結束程式。不想開視窗可加 `--no-gui`。

說出項目後會直接朗讀。可用的語音指令:

| 說 | 動作 |
|---|---|
| 項目名稱、別名或編號(如「電源開關測試」「TC 零二三」) | 朗讀該項目的步驟 |
| 重複 / 再說一次 | 重新朗讀上一個項目 |
| 結束 / 離開 | 離開程式 |

辨識結果不夠確定時,程式會問「請問是 TC-023 喇叭音量測試 嗎?」,回答「是」或「不是」即可。
朗讀時麥克風是關閉的(避免喇叭聲被收進去),念完才會繼續聆聽。

## 對照表

專案附的是**範例**資料 `procedures.sample.xlsx`(5 筆假資料),下載後不用設定就能直接試。

要用自己的資料時:複製一份範例檔,改名成 **`procedures.xlsx`**,放在程式資料夾裡,內容換成你的項目。程式會優先使用 `procedures.xlsx`,找不到才用範例。也可以用 `--excel 檔案路徑` 指定任何位置的檔案。

`procedures.xlsx` 已被 `.gitignore` 忽略,**只存在你自己的電腦上,不會被 commit**,所以內容不會外流到公開的 GitHub。請不要把含真實資料的 Excel 改名後放進專案。

第一列是欄位名稱,欄位為 `編號、名稱、別名、步驟`:

- **別名**(選填,可整欄留空):用 `;` 或 `、` 分隔,說別名也找得到
- **步驟**:同一格內一行一個步驟(Alt+Enter 換行)。不用自己寫「1.」「第一步」,程式會自動加上
- `python make_sample_excel.py 新檔名.xlsx` 可重新產生一份範例

## 常用選項

| 選項 | 說明 |
|---|---|
| `--devices` | 列出音訊裝置。預設用系統預設裝置;戴耳機時把耳機設為預設即可 |
| `--in-device 2` / `--out-device 4` | 指定麥克風/播放裝置(編號或名稱) |
| `--rate -10%` | 朗讀變慢(`+20%` 變快) |
| `--threshold 400` | 環境吵、容易誤觸發時調高音量門檻 |
| `--no-gui` | 不開大字視窗,只用文字介面(Ctrl+C 結束) |
| `--text` | 不用麥克風,改用鍵盤輸入(測試用) |
| `--list` | 列出對照表內容 |

## 網頁版(手機、平板、其他電腦)

`web/` 資料夾是純靜態網頁,Android、iPhone、Mac、Windows 的瀏覽器都能開(建議 Chrome / Edge / Safari)。
功能與桌面版相同:說項目名稱或編號 → 朗讀步驟(念到的那一步標亮),也可以打字查詢。

在自己電腦上試(`localhost` 允許使用麥克風):

```bash
python -m http.server 8765 --directory web
```

然後開 http://localhost:8765 。手機要用麥克風必須是 **HTTPS**,所以手機請用下面的 GitHub Pages 網址。

**對照表不放在專案裡。** 網頁開啟後,到「資料與設定」按「載入 Excel / CSV」選你自己的檔案。檔案只在該裝置的瀏覽器裡處理並存在本機(localStorage),不會上傳;沒載入時用 `web/sample.json` 的範例資料。`.gitignore` 已忽略所有 `.xlsx`(只放行 `web/sample.xlsx` 範例),避免不小心 commit。

**發布到 GitHub Pages:** 把專案推上 GitHub 後,到 Settings → Pages → Source 選「GitHub Actions」,之後每次改 `web/` 並推到 `main` 就會自動發布(設定檔在 `.github/workflows/pages.yml`)。
注意:Pages 網站是**公開**的(即使專案是 private,免費方案甚至不能對 private 專案開 Pages),所以專案裡只能放程式與範例資料。

**聆聽模式(畫面上方的切換鈕,會記住你的選擇):**
- **常開監聽**:按「開始」後一直聽,適合安靜環境。
- **按住說話**:按住大按鈕才收音,放開就結束,適合吵雜環境;電腦上也可以按住空白鍵。按住時如果正在朗讀會先停下來,方便插話。
- **點擊監聽**(手機上的第二種模式,電腦上叫「按住說話」):大按鈕和常開監聽一樣是「開始 / 停止」,差別在於只聽一句話——按「開始」後說話,**說完停頓就自動停止**,也可以按「停止」提早結束,然後等結果念出來;要問下一個再按一次「開始」。手機不用「按住」的原因:iPhone 的 Safari 對按住收音、持續收音都不穩定,Android 的 Chrome 持續收音會重複吐字。iPhone 預設用這個模式;Android 預設是常開監聽,可自行切換。
- **常開監聽**適合雙手正忙的時候;環境太吵時改用「點擊監聽」(電腦則是按住說話)。念步驟時麥克風是關的,念完才會繼續聽。
- iPhone 也要求「朗讀必須在點擊的當下解鎖」,所以請用點按鈕的方式操作,並確認側邊靜音撥片沒開。
- **打字查詢清單**:在下方輸入框輸入幾個字(可用空白分成多個關鍵字,例如「usb 傳輸」),上方會即時列出編號、名稱或別名含有這些字的所有項目,顯示完整編號與名稱;點一下項目就朗讀。「清單」按鈕可顯示全部項目。想不起來確切名稱時,先查清單,再用語音說完整的編號或名稱。
- 程式不確定你說的是哪一項時,會問「請問是…嗎?」,畫面上同時出現大的「是 / 不是」按鈕,可以直接點,也可以用說的回答。
- 頁面下方「資料與設定 → 診斷紀錄」會記下收音與朗讀的每一步,遇到問題時截圖即可。語音辨識不穩時,iPhone 可以改點輸入框、用鍵盤上的麥克風聽寫。

和桌面版的差異:
- 語音辨識與朗讀都由瀏覽器/手機提供,聲音品質依裝置而定;辨識需要網路(Chrome/Edge 送到 Google、Safari 送到 Apple)。
- iPhone 要先點「開始」才能發聲與收音,之後每一輪是否自動聆聽取決於 Safari;若停下來,再點一次「開始」。
- 比對沒有簡繁轉換,Excel 內容請和辨識結果用同一種字(繁體手機通常辨識成繁體)。
- 第三方程式:`web/vendor/xlsx.full.min.js` 是 SheetJS 0.20.3(讀 Excel 用),原始碼來自 https://cdn.sheetjs.com 。

## 注意

- 線上辨識使用 `SpeechRecognition` 內建的 Google Web Speech 免費介面,適合內部工具與原型;若要正式大量使用,建議改接有正式授權的服務(如 Azure Speech)。
- 預設麥克風若是「Virtual Microphone」之類的虛擬裝置,請用 `--in-device` 改指定實體麥克風或耳機。
- 「網路沒有連線」的語音提示使用 Windows 內建中文語音(需已安裝中文(繁體)語音:設定 > 時間與語言 > 語言與區域)。
- 檔案:`main.py`(流程)、`procedures.py`(Excel 與比對)、`speech_io.py`(辨識與朗讀)、`ui.py`(大字視窗,字體大小在這個檔案裡改)。
